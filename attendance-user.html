ユーザーの作業

管理者の準備ができたあと、くみあぷ（PairGen）で組み合わせを作る人と、参加者が行う作業です。準備がまだのときは、管理者の作業を先に済ませてください。全体の仕組みは全体像にあります。

だれがどこでやること
組み合わせを作る人くみあぷ（PairGen）出欠表（Web アプリ）を登録し、必要なときに読み込む（1・3・4）
参加者ブラウザ（スマートフォンで可）出欠表に、名前の登録と出欠の入力をする（2）
  • 1. くみあぷ（PairGen）にウェブアプリを登録する（管理者）
  • 2. 参加者の作業（Web アプリ）
    • 画面上部の注意書きについて
    • ユーザーを登録する
    • イベントを登録する
    • イベントの参加を登録する
  • 3. くみあぷ（PairGen）で読み込む
  • 4. 登録内容を変更する

1. くみあぷ（PairGen）にウェブアプリを登録する（管理者）

くみあぷ（PairGen）に「出欠表はここにあります」と教えておく作業です。組み合わせを作る人が、1 回だけ行います。管理者の作業で控えたウェブアプリの URLと READ_KEY を使います。

  1. プレイヤータブの左上の「…」メニューから「グループ管理」を開きます。
  2. 「新しいグループ」の一番上で「Google スプレッドシート」を選びます。
  3. 次の 3 つを入力します。
    • グループ名（好きな名前）
    • スプレッドシートの URL（ウェブアプリの URL）
    • READ_KEY
  4. 「追加」をタップします。
URL はhttps:// で始まるウェブアプリの URL です。3 つとも入力すると「追加」が押せるようになります。

登録すると、「グループ」の一覧に、地球儀のアイコンが付いた青い下線付きの名前で表示されます。この名前をタップすると、登録した Web アプリが、端末の既定のブラウザで開きます。出欠を確認したいときや、イベントを登録したいときに、すぐ Web アプリへ移動できます。

Web アプリを開くときに、READ_KEY は送られません。初回は「合言葉入力」の入力欄が出るので、管理者から教わった ACCESS_KEY を入れてください。
スプレッドシートのグループには、プレイヤーを手動で登録することはできません。メンバーは、読み込むたびにスプレッドシートから作られます。

2. 参加者の作業（Web アプリ）

参加者が出欠を入力する場所が、Web アプリ（出欠表）です。アプリのインストールは要りません。参加者は、管理者から教わったウェブアプリの URLをブラウザ（スマートフォンでも可）で開きます。初回は「合言葉入力」の入力欄が出るので、管理者から教わった ACCESS_KEY を入れて「開く」をタップします。

画面は日本語で表示されます。右上の「English」で英語に切り替えられます。

操作の流れは、動画でも見られます。

YouTube で見る

画面上部の「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」について

Web アプリを開くと、画面の上に青い帯で次のように表示されます。

このアプリケーションは Google Apps Script のユーザーによって作成されたものです　［不正行為を報告］［詳細］［×］
  • これは、Google Apps Script で作られた Web アプリであれば、どれにも Google が自動で表示する注意書きです。このアプリに問題があるという意味ではありません。
  • この Web アプリは、あなたの所属するグループの管理者が用意したものです。管理者から教わった URL であれば、そのまま使って問題ありません。
  • 帯は、右端の「×」で閉じられます。閉じなくても、使い方には影響しません。
  • 「不正行為を報告」は、Google に不正なアプリとして報告するためのボタンです。誤って押さないようにしてください。
管理者から教わっていない URL でこの表示が出たときは、入力を進めず、管理者に確認してください。

ユーザーを登録する

初めて使う人は、先に自分の名前を登録します。

  1. 「新規ユーザー登録」の入力欄に名前を入れます。この名前が、くみあぷ（PairGen）のプレイヤー名になります。
  2. 「レベル」を選びます（1〜3）。このレベルが くみあぷ（PairGen）にも反映されます。
  3. 「追加」をタップします。

登録すると、「利用ユーザーを選択」のリストに名前が出ます。出欠を入力するときは、このリストから自分の名前を選びます。

くみあぷ（PairGen）には、ここで登録した名前がそのまま表示されます。他の参加者と区別できる名前にしてください。

イベントを登録する

練習日などの予定をカレンダーに登録します。誰か 1 人が登録すれば、全員に表示されます。

  1. カレンダーで、イベントの日付をタップします。
  2. 「イベントを作成」の画面で、時間帯（開始と終了）と場所を入力します。場所は、リストから選ぶか「+ 新しい場所を入力」で入力します。
  3. 「イベント作成」をタップします。
画面を開いたときは、先月・当月・翌月のデータを読み込みます。ほかの月へ移動したときは、その月のデータを読み込むので、読み込み中は日付をタップできません。少し待つとタップできるようになります。

登録したイベントは、カレンダーの日付の下に場所が表示されます。間違えて作ったイベントは、日付をタップして「このイベントを削除する」で消せます。

イベントの参加を登録する

  1. 「利用ユーザーを選択」で自分の名前を選びます。
  2. カレンダーでイベントの日付をタップします。
  3. 「参加」「不参加」「保留」のどれかをタップします。

あとから変更したいときは、同じ画面でもう一度選び直します。

押すボタンくみあぷ（PairGen）での扱い
参加出場
保留休憩
不参加／まだ押していないデフォルト欠席
予定が決まらないときは「保留」にしておくと、くみあぷ（PairGen）では休憩として一覧に載ります。当日に来られることになったら、くみあぷ（PairGen）側でチェックを入れるだけで出場に切り替えられます。

3. くみあぷ（PairGen）で読み込む

操作の流れは、動画でも見られます。

YouTube で見る

  1. プレイヤータブの左上の「…」メニューから「グループ読込」を開きます。
  2. 地球儀のアイコンが付いたグループが、Google スプレッドシートのグループです。タップします。
  3. 出欠表から、直近のイベントの参加者が、プレイヤー一覧に読み込まれます。
  • イベントが見つかったときは、プレイヤー一覧の見出しが「グループ名 日付」になります。イベントがないときは、グループ名だけです。
  • 読み込み中は、画面に待機の表示が出ます。通信に失敗したときは、メッセージが出て、今の一覧はそのままです。
  • 同じイベント日に読み込み直すと、試合の記録を残したまま出欠だけ更新されます。詳しくは全体像を見てください。

4. 登録内容を変更する

URL や READ_KEY が変わったときは、「グループ管理」を開き、そのグループの鉛筆アイコンをタップします。グループ名、URL、READ_KEY を直して「保存」をタップします。

グループを消したいときは、ゴミ箱アイコンをタップします。スプレッドシートのデータは消えません。

うまく読み込めないときは、全体像の「困ったとき」を見てください。
